📤 COMO ENTREGAR A ATIVIDADE - APS_02

  • 1 Complete o Desafio do Tema 2 (acesse o link "Desafio - Tema 2" acima)
  • 2 Capture a tela do resultado final do desafio (mostrando sua resposta/conclusão)
  • 3 Crie um repositório no GitHub com o nome "APS_02"
  • 4 Envie a captura de tela para o repositório APS_02
  • 5 Publique seu projeto Anvil (Sistema de Diploma) e adicione o LINK no arquivo README.md do repositório
  • 6 Preencha o formulário abaixo com o link do repositório APS_02
📌 Estrutura esperada do seu repositório APS_02: 
APS_02/
├── README.md           (contém o link do seu aplicativo Anvil)
└── captura_desafio.png (sua captura de tela do desafio)

🔗 Exemplo de README.md:

# APS_02 - Tecnologia e Sistemas de Informação

## Link do Aplicativo Anvil

## Captura do Desafio

📝 CLIQUE AQUI PARA ENVIAR O LINK DO REPOSITÓRIO
📌 Informações solicitadas no formulário:
  • 📅 Data da atividade
  • 👤 Nome do aluno
  • 🔗 Link para o repositório da atividade (cole o link do seu GitHub APS_02)

⚠️ Importante: O formulário pede o LINK DO REPOSITÓRIO (não o link do Anvil separadamente). O link do Anvil deve estar dentro do README.md do seu repositório.
