🎮 Prepare-se para o Kahoot! 15 questões - clique para revelar
1. O que significa a sigla IoT?
✅ Internet das Coisas (Internet of Things) - conexão de objetos à internet
2. Qual arquitetura permite pagar apenas pelo que usar?
✅ Computação em Nuvem (Cloud Computing) - modelo de pagamento por uso
3. Qual princípio da segurança garante dados não alterados?
✅ Integridade - garante que dados não sejam corrompidos ou alterados
4. SQL é utilizado para manipular qual tipo de sistema?
✅ Bancos de Dados Relacionais - Structured Query Language
5. O que é Machine Learning?
✅ Subárea da IA que permite máquinas aprenderem com dados
6. Qual tecnologia permite múltiplos SO em um servidor?
✅ Virtualização - cria ambientes virtuais isolados
7. O que significa SOA?
✅ Arquitetura Orientada a Serviços - serviços reutilizáveis
8. Qual componente NÃO faz parte de um SI?
✅ Apenas hardware - SI tem: hardware, software, dados, redes e pessoas
9. O que é Phishing?
✅ Fraude eletrônica que tenta obter dados pessoais
10. Qual tecnologia transforma dados em insights?
✅ Business Intelligence (BI) e Data Analytics
11. O que é um Data Center?
✅ Instalação física com servidores e equipamentos de rede
12. Qual das opções é um SGBD?
✅ MySQL, PostgreSQL, Oracle, SQL Server - todos são SGBDs
13. O que é Ransomware?
✅ Malware que sequestra dados e exige resgate
14. Qual a função do firewall?
✅ Controlar tráfego de rede e bloquear acessos não autorizados
15. O que é Big Data?
✅ Grandes volumes de dados que exigem processamento especializado
